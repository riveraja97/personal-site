## 💻 Getting Started

This website is built with HTML, CSS, and vanilla
JavaScript. No build tools or package installation
are required.

### 1. Clone the Repository

```bash
git clone https://github.com/riveraja97/YOUR-REPOSITORY-NAME.git
```

Replace `YOUR-REPOSITORY-NAME` with the actual
name of this portfolio repository.

### 2. Open the Project

```bash
cd YOUR-REPOSITORY-NAME
```

Open the folder in Visual Studio Code or
another code editor.

### 3. Run the Website

Open `index.html` in your browser.

Alternatively, use the VS Code Live Server
extension to preview the website locally.

### 4. Customize the Content

Edit the following files:

- `index.html` for personal content and résumé links
- `style.css` for colors, layouts, and visual styling
- `script.js` for featured projects, case studies,
  diary entries, and GitHub configuration

## 🔗 GitHub API Integration

The portfolio uses the public GitHub REST API to
retrieve repository information dynamically.

The GitHub username is configured in `script.js`:

```javascript
const GITHUB_USERNAME = "riveraja97";
```

The website fetches public repositories and
displays them as interactive project cards.

Visitors can search, sort, and explore repositories
without manually updating the gallery.

**Note:** GitHub's unauthenticated API has rate limits.
If the limit is reached, the gallery may temporarily
display an error message.

The gallery only displays public repositories and
does not require an API key.
